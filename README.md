"# Book Catalog

A full-stack application for managing a book catalog with authors. Built with Laravel (backend) and React (frontend).

## Features

- Book management (CRUD operations)
- Author management
- User authentication
- API endpoints
- Responsive UI

## Backend (Laravel)

### Setup

```bash
cd books
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Testing

```bash
php artisan test
```

## Frontend (React)

### Setup

```bash
cd frontend
npm install
npm start
```

### Testing

```bash
npm test
```
